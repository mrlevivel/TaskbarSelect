# Taskbar Select Artwork

## Current Sources

Since 2026-09-26, the app uses an original rounded toolbar family and balanced Monitor Check application mark. These use newly authored geometry for familiar UI symbols, replacing the previous Lucide-derived toolbar and monitor/check artwork.

- Toolbar editable sources: `assets/toolbar/svg/{refresh,undo,pause,play,plus,info,keyboard}.svg`.
- Application mark editable source: `assets/taskbar-select.svg` (Monitor Check).
- Toolbar outputs: seven dark/light PNG pairs directly under `assets/toolbar`, at 32x32 pixels.
- Application outputs: `assets/TaskbarSelect.ico` and `assets/taskbar-select-preview.png`, generated by `Build-Icon.cjs`.

The application mark's monitor outline, checkmark, taskbar stripe and stand use matching four-unit rounded strokes. Checked-in sources are sufficient for regeneration; local review artifacts are not build inputs.

## Regeneration

Use Node.js with `sharp` available through normal Node module resolution (or a caller-configured `NODE_PATH`):

```powershell
node .\Build-ToolbarIcons.cjs
node .\Build-Icon.cjs
```

The toolbar renderer reads only the local SVG sources and does not fetch artwork. Optional arguments select existing resource stems, for example `node .\Build-ToolbarIcons.cjs refresh-cw info`. `refresh.svg` maps to `refresh-cw-{dark,light}.png` and `undo.svg` maps to `undo-2-{dark,light}.png`; the remaining source and resource stems match. The retained names keep runtime resource lookups unchanged.

Standard colors remain `#263238` in light mode and `#e6e9ec` in dark mode. Information markers remain subdued: `#65727b` in light mode and `#8f9aa2` in dark mode. The UI uses 18 px toolbar symbols and 14 px information markers. `sharp` is an image-conversion dependency, not the source of the designs.

## Historical Artwork

Earlier versions used Lucide 0.468.0 toolbar icons and a Lucide `monitor-check` adaptation for the app mark. Their unchanged notice is archived at `assets/legacy/lucide-LICENSE.txt`, with context in `assets/legacy/README.md`. Do not remove notices from earlier distributed packages.


Current package inputs use the replacement artwork and include this provenance document rather than the historical Lucide notice. The unused `ellipsis` and `rotate-ccw` PNG pairs are no longer source or embedded resources.

This document records design provenance, not trademark clearance or exclusive ownership of familiar symbols. Windows controls, fonts and platform components remain separate dependencies.
