# Historical Artwork Notice

`lucide-LICENSE.txt` is the unchanged Lucide 0.468.0 notice previously stored at `assets/lucide-LICENSE.txt`. Earlier Taskbar Select versions used Lucide toolbar artwork and an application mark adapted from `monitor-check`.

The 2026-09-26 replacement uses the approved original Rounded (A) toolbar family and balanced Monitor Check application mark. The archived notice is retained for repository history and earlier artwork, not included in new installer or portable packages. It does not change the attribution or notices that accompanied earlier distributed versions.

Current editable sources and regeneration details are documented in `assets/ARTWORK.md` at the repository root. Historical changelog and testing entries remain unchanged.
